## 产品概述

这是一个 RAG（检索增强生成）系统的幻觉缓解实验项目，旨在对比四种不同策略在减少大语言模型幻觉方面的效果。

## 核心功能

### 实验条件（4种）

1. **LLM Only**: 无检索组件，纯参数化生成，作为最高幻觉基线
2. **Vanilla RAG**: 标准检索-生成流程，top-k=3 文档拼接到 prompt
3. **LangChain Structured Chain**: 强制引用机制 [Source N]，链式思考，512-token 分块 + 10% 重叠
4. **Self-RAG**: 检索器 + LLaMA-3.1-8B，生成反思 token 判断检索必要性和答案可信度

### 评估要求

- 每领域 100 个响应
- 生成器：LLaMA-3.1-8B-Instruct
- 检索器：Hybrid RRF
- 主指标：FActScore（细粒度原子事实评估）
- 辅助指标：EM, F1, Hallucination Rate, Citation Precision/Recall
- 人工评估：50 个样本的引用准确性

### 数据集

- FinanceBench（金融）
- CUAD / LegalBench-RAG-mini（法律）

## 技术栈

- **语言**: Python
- **编排框架**: LangChain
- **生成模型**: LLaMA-3.1-8B-Instruct
- **检索器**: Hybrid RRF (BM25 + Contriever)
- **评估工具**: FActScore, 自定义指标
- **硬件**: NVIDIA A100 40GB

## 实现方案

### 架构设计

基于现有项目结构扩展，采用模块化设计：

- 复用现有检索器（BM25, Contriever, Hybrid RRF）
- 新增幻觉缓解策略模块
- 扩展评估指标模块

### 关键实现要点

1. **LLM Only 基线**: 直接调用生成器，不传入检索文档
2. **Vanilla RAG**: 已有 RAGSystem 实现，需适配 LLaMA 模型
3. **LangChain Structured Chain**: 

- 使用 RetrievalQA 链
- 自定义 PromptTemplate 强制引用格式
- 实现 512-token 分块 + 10% 重叠

4. **Self-RAG**: 

- 实现反思 token 生成（Rel, Ret, IsRel, IsSup 等）
- 检索必要性判断
- 答案可信度评估

### 性能考量

- 批量处理减少 API 调用开销
- 缓存检索结果避免重复计算
- 使用 float16 运行嵌入模型节省显存
