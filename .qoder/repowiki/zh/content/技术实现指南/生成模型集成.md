## 简介

本项目专注于检索增强生成（Retrieval-Augmented Generation, RAG）系统的设计与实现，现已发展为支持多种生成模型架构的综合性平台。系统通过将神经检索与大型语言模型相结合，从外部文档中检索相关信息来支撑生成过程，从而提高答案的准确性、可信度和鲁棒性。

**更新** 项目现已支持LLaMA和Qwen等多种开源生成模型，提供统一的模型接口和配置管理，实现了真正的多模型架构支持。

### 批量生成优化

**更新** 支持批量推理以提高吞吐量：

```python
def generate_batch(
    self,
    questions: List[str],
    documents_list: List[List[Dict]],
    **generation_kwargs
) -> List[Dict]:
    """批量生成答案，优化GPU利用率"""
    results = []
    for question, documents in zip(questions, documents_list):
        result = self.generate(question, documents, **generation_kwargs)
        results.append(result)
    return results
```

## 故障排除指南

### 常见问题及解决方案

#### 检索性能问题
1. **检索速度慢**
   - 检查索引构建质量
   - 调整搜索参数
   - 实施缓存机制

2. **检索质量差**
   - 优化查询预处理
   - 调整相似度阈值
   - 增加训练数据

#### 生成质量异常
1. **答案不准确**
   - 检查上下文质量
   - 调整生成参数
   - 使用更高质量的检索结果

2. **幻觉现象**
   - 实施证据验证
   - 使用更严格的过滤
   - 增加人工审核

#### 资源管理问题
1. **内存溢出**
   - 减少批处理大小
   - 启用梯度检查点
   - 使用混合精度

2. **GPU利用率低**
   - 检查数据管道
   - 优化批处理策略
   - 调整并行度

#### 多模型集成问题
1. **模型加载失败**
   - 检查HuggingFace模型ID
   - 验证网络连接
   - 清理缓存目录

2. **提示模板错误**
   - 确认模型类型匹配
   - 检查特殊标记符
   - 验证上下文格式
